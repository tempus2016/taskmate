# Project Conventions

## Git

- **Branch naming**: Always use `taskmate/` prefix (e.g. `taskmate/dynamic-chore-visibility`). Never use `claude/` or other prefixes.
- **Author/Committer**: All commits must use:
  - Name: `tempus2016`
  - Email: `john_mackinnon@live.co.uk`
- **Before committing**, ensure `git config user.name` and `git config user.email` are set to the above values.
- Do not commit, push, create PRs, or merge under any other identity.
